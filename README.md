## Monitor de Resiliencia Agrícola y Sequía (Hidrología + Agro)

El Problema: Andalucía es el motor agrícola de España (aceite, invernaderos, etc.), pero la sequía y la gestión del agua son problemas críticos y recurrentes de altísimo interés público y económico.

Datos de la Junta: Datasets sobre el estado de los embalses, precipitaciones/meteorología (Red RIA), y registros de explotaciones agrarias.

Reto de Data Engineering: * Crear una pipeline automatizada (ETL/ELT) que ingeste diariamente datos meteorológicos y niveles de embalses.

Cruzar estos datos con bases de datos geoespaciales (GIS) de zonas de cultivo.

Entregable: Un Data Warehouse automatizado que alimente un cuadro de mando público, o una API propia que los agricultores puedan consultar para prever restricciones de agua basadas en datos históricos y actuales.
